＋ pixivアカウントを追加

この画面だけで追加できます。サーバーへのSSHは不要です。 code は発行から数十秒で失効するため、ログイン後すぐに貼り付けてください。

  1. 「ログインURLを発行」を押し、表示されたリンクを開きます。
  2. ログインする前に F12（Macは ⌘+⌥+I）で開発者ツールを開き、Network タブの Preserve log を有効にします。
  3. 追加したいアカウントでログインします。白いページ、またはpixivアプリへ移動したような画面になりますが、正常です。
  4. Network 一覧の callback?…code=… を右クリック →「Copy link address」（Firefoxは「URLをコピー」）でURLをコピーします。検索欄に callback と入れると絞り込めます。
  5. 下の欄に貼り付けて「このアカウントを追加」を押します。
pixivログインを開く

うまくいかないとき: ログイン済みの状態で「pixivログインを開く」を押すと新しい code が発行されます。Network の記録が空の場合は、DevToolsを開いたまま再読み込みしてください。
